Four counts. One allowance check.

Needed sends = campaign + reserved resends + other sends. Subtract that total from the balance left now. Check the provider's live counter and reset before sending; this arithmetic does not verify daily caps, delivery, fees or a plan recommendation.

The prefilled numbers are examples. The widget requires JavaScript. Its four inputs stay in the widget page's memory; its calculation code does not save or send them, add them to a URL, or collect recipient addresses. The widget contains no affiliate links or application view analytics.

Loading it still requests public HTML, CSS and JavaScript from its host. GitHub and hosting/security services can process ordinary requests. Opening the full tool loads a normal planning page with separate aggregate counts. See Send Budget's privacy notice.
